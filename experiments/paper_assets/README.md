# Paper Assets (Overleaf-Ready)

This folder is the consolidated paper package for the HCI Bimodal Affective Alignment project.

## Folder Contents
- `diagrams/`: architecture and workflow visuals (pipeline-level diagrams).
- `figures/`: evaluation/result plots for paper and slides.
- `tables/`: CSV, Markdown, and LaTeX table assets.
- `overleaf_assets.tex`: figure/table inclusion blocks and subsection draft text.
- `figure_captions.md` and `table_captions.md`: ready-to-use caption text.
- `paper_strengtheners.md`: contributions, limitations, threats to validity, reproducibility, and robustness wording.
- `presentation_assets.md`: concise slide-ready talking points.
