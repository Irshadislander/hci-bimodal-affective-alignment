# Human Rating Instructions

## Purpose
This evaluation sheet is used to assess how well each system mode communicates emotion and supports the user in a short HCI-style interaction.

## Who Should Rate
Use evaluators who can read the user text and response independently and judge the interaction quality from a human perspective. A small course-project panel is sufficient.

## What To Do
- Enter one `rater_id` and keep the same identifier for every row you complete.
- Read the user text, detected emotion, and system response for each case.
- Rate each row on the four criteria below using the 1-5 scale.
- Add short notes when a response feels especially strong, weak, or surprising.
- Leave notes blank only if you have nothing useful to add.

## Rating Scale
| Score | Meaning |
| --- | --- |
| 1 | Very poor |
| 2 | Weak |
| 3 | Okay |
| 4 | Good |
| 5 | Excellent |

## Rating Dimensions
### Empathy
Does the response acknowledge the user’s emotional state and feel appropriately supportive?

### Social Presence
Does the response feel like it is addressing a real person rather than producing a mechanical reply?

### Trust
Does the response feel credible, safe, and consistent with the detected emotion?

### Helpfulness
Does the response provide a useful framing or next step for the interaction?

## Mode Labels
The sheet uses these labels for the three comparison modes:
- `Text only`
- `Face only`
- `Fused`

These correspond to the text-only baseline, the face-only baseline, and the weighted multimodal system.

## Notes for Evaluators
- Rate the response quality, not the implementation details.
- Use the same `rater_id` for all rows completed by the same person.
- Short notes are optional, but they are useful for explaining unusual ratings or strong comparisons.
